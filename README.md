A highly polished, visually stunning **Memory Match Game** developed as a semester project for the **Web Technologies (WT)** course. Built entirely from scratch using vanilla technologies, focusing heavily on modern UI/UX design, micro-interactions, and performance.

## ✨ Features

- 🎨 **Ethereal Glassmorphism UI**: A deep, vibrant dark-mode aesthetic featuring translucent glass panels, floating glowing orbs, and a modern typography system (Outfit font).
- 🌌 **3D Hover Micro-interactions**: Cards physically tilt and react to your mouse movements in 3D space.
- 💥 **Dynamic Particle Animations**: Custom-built particle explosion effects trigger on every successful match, culminating in a celebration sequence when you win.
- 🐾 **Animal Emojis**: A fun, curated set of animal icons to match.
- 🏆 **High Score System**: Automatically tracks and saves your fastest time using the `localStorage` API.
- 🎵 **Immersive Audio**: Ambient background music and synchronized sound effects (flip, match, shake/wrong).
- 📱 **Fully Responsive**: Optimized fluid grid layout for desktop, tablet, and mobile screens.

## 🎮 How to Play

1. **Start**: Click any card to reveal its animal. (The timer starts on your first click!)
2. **Match**: Find the second card with the same animal to clear the pair.
3. **Win**: Clear all 8 pairs in the shortest time and fewest moves.
4. **Record**: Beat your "Best Time" to earn the "New Personal Best! 🏆" badge.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and SVG icon integration.
- **CSS3**: Advanced features used including CSS Variables, backdrop-filter, 3D transforms (`perspective`, `rotateX/Y`), and complex `@keyframes` animations.
- **Vanilla JavaScript (ES6+)**: Game logic, DOM manipulation, 3D physics calculations, dynamic particle generation, and Local Storage API.
