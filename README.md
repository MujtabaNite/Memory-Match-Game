A premium, high-performance **Memory Match Game** built with vanilla technologies. Experience a sleek, modern UI with smooth animations, immersive soundscapes, and personal best tracking.

## ✨ Features

- 🎨 **Premium UI**: Modern dark-mode aesthetic with glassmorphism and animated background blobs.
- ⚡ **Match Pulse**: Satisfying visual feedback when you find a pair.
- 🏆 **High Score System**: Automatically tracks and saves your fastest time using `localStorage`.
- 🎵 **Immersive Audio**: Ambient background music and synchronized sound effects (flip, match, wrong).
- 🔇 **Mute Toggle**: Control your audio experience with a dedicated button.
- 📱 **Fully Responsive**: Perfectly optimized for desktop, tablet, and mobile screens.
- 🚀 **Zero Dependencies**: Pure HTML, CSS, and Vanilla JS for maximum performance.

## 🎮 How to Play

1. **Start**: Click any card to reveal its icon.
2. **Match**: Find the second card with the same icon to clear the pair.
3. **Win**: Clear all 8 pairs in the shortest time and fewest moves!
4. **Record**: Beat your "Best Time" to see the "New Personal Best! 🏆" badge.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox/Grid, and Keyframe animations.
- **JavaScript (ES6+)**: Game logic, DOM manipulation, and Local Storage API.
- **Audio API**: Dynamic sound management and looping background music.

## 🚀 Deployment

This project is designed to be hosted on platforms like **Vercel** or **GitHub Pages**.

To deploy on Vercel:
1. Push your code to GitHub.
2. Connect your repo to Vercel.
3. Vercel will automatically detect the `index.html` and deploy it as a static site!
